# Unistax Frontend

Composable frontend components for building unified full-stack applications.

## Installation

```bash
npm install @unistax/frontend
# or
yarn add @unistax/frontend
```

## Development Installation

```bash
# Clone the repository
git clone https://github.com/AaronHonour/unistax.git
cd unistax/frontend

# Install dependencies
npm install
```

## Usage

```typescript
import { YourComponent } from '@unistax/frontend';

// Example usage here
```

## Development

### Building

```bash
npm run build
```

### Running Tests

```bash
npm test

# Watch mode
npm run test:watch

# With coverage
npm run test:coverage
```

### Code Quality

```bash
# Lint
npm run lint

# Fix lint issues
npm run lint:fix

# Type checking
npm run typecheck

# Format code
npm run format
```
