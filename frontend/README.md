# Toolkit Frontend

JavaScript/TypeScript toolkit providing reusable components and utilities for frontend development.

## Installation

```bash
npm install @toolkit/frontend
# or
yarn add @toolkit/frontend
```

## Development Installation

```bash
# Clone the repository
git clone https://github.com/AaronHonour/toolkit.git
cd toolkit/frontend

# Install dependencies
npm install
```

## Usage

```typescript
import { YourComponent } from '@toolkit/frontend';

// Example usage here
```

## Development

### Building

```bash
npm run build
```

### Running Tests

```bash
npm test

# Watch mode
npm run test:watch

# With coverage
npm run test:coverage
```

### Code Quality

```bash
# Lint
npm run lint

# Fix lint issues
npm run lint:fix

# Type checking
npm run typecheck

# Format code
npm run format
```
