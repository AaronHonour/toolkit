# Unistax

High-performance composable full-stack framework for building production-ready applications.

## Features

- **Database**: SQLAlchemy integration with optimizations
- **API**: FastAPI utilities and patterns
- **Tasks**: Celery integration for background jobs
- **Tracing**: Distributed tracing support
- **Caching**: Redis and in-memory caching
- **Queue**: Message queue backends
- **Storage**: File and blob storage abstraction
- **Algorithms**: High-performance algorithms (hashing, search, etc.)
- **Performance**: Profiling and optimization tools

## Installation

```bash
pip install unistax
```
